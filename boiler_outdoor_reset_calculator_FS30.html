Calculation

Setpoint = 85 + (Outdoor + 23) × (−20 / 41)

The curve is calculated as Tset = T1 + (Tout − Tout1) × (T2 − T1) / (Tout2 − Tout1).

Values beyond the two reference temperatures are linearly extrapolated, not limited to the reference setpoints. Actual boiler controls may impose minimum/maximum setpoints or warm-weather shutdown.

How the setpoint is calculated (original endpoints)

Based on the two reference points: −23°C outdoors → 85°C boiler and +18°C outdoors → 65°C boiler.

Step 1 — Calculate the slope
m = 65 − 8518 − (−23) = −0.4878
Step 2 — Substitute the reference point to find the equation
Tboiler = 73.7805 − 0.4878Toutside

The setpoint decreases by approximately 0.488°C for every 1°C rise in outdoor temperature. For example, at 0°C outdoors, the calculated boiler setpoint is 73.8°C.

This derivation uses the original endpoints. The main calculator and graph update if you edit the reference values. Outside the two endpoints, results are linear extrapolations.
